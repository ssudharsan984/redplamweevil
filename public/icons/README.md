# PWA Icons

Place the following PNG icon files in this directory (`public/icons/`):

| File                  | Size       |
|-----------------------|------------|
| icon-72x72.png        | 72×72 px   |
| icon-96x96.png        | 96×96 px   |
| icon-128x128.png      | 128×128 px |
| icon-144x144.png      | 144×144 px |
| icon-152x152.png      | 152×152 px |
| icon-192x192.png      | 192×192 px |
| icon-384x384.png      | 384×384 px |
| icon-512x512.png      | 512×512 px |

## Quick Generation

Use https://realfavicongenerator.net or https://www.pwabuilder.com/imageGenerator
to generate all sizes from a single source image.

The icon-192x192.png and icon-512x512.png are marked as `purpose: "any maskable"`
and are required for Android APK generation via PWA Builder.
